SITIO WEB PORTFOLIO — ARQUITECTA FREELANCER

Objetivo principal
Crear una landing / portfolio de alto impacto para promocionar servicios de arquitectura, interiorismo y visualización 3D como freelancer. La página debe ayudar a que una persona que llega desde Workana entienda rápido la calidad del trabajo, el tipo de proyectos realizados y por qué conviene contratarla.

Restricciones importantes
- No incluir teléfono, email, WhatsApp, Instagram ni datos de contacto externos.
- El único CTA debe orientar a contratar o continuar por Workana.
- No usar la palabra “vendibles”. Reemplazar por términos como: claros, presentables, profesionales, atractivos, con criterio arquitectónico, visualmente sólidos.
- No afirmar que un proyecto fue construido si no está explícitamente indicado.
- Usar lenguaje elegante, directo y profesional.
- La página debe ser moderna en efectos y transiciones, pero sobria y estética. Las animaciones deben acompañar a los renders, no competir con ellos.

Experiencia visual general
La web debe sentirse editorial, premium y arquitectónica. Debe priorizar imágenes grandes, tipografía limpia, fondos cálidos, transiciones suaves y microinteracciones cuidadas. Inspiración general: portfolios de arquitectura contemporánea, estudios de interiorismo premium, páginas con scroll narrativo y reveal de imágenes.

Stack esperado
- React
- CSS moderno o Tailwind si el proyecto ya lo usa
- GSAP
- ScrollTrigger
- Framer Motion opcional solo si aporta valor
- Lenis o smooth scrolling si está disponible
- Skills disponibles dentro de .claude, especialmente las relacionadas con GSAP / ScrollTrigger / animaciones de scroll

Criterio de implementación
- Componentizar por sección.
- Centralizar la información de proyectos en un archivo de datos.
- Usar imports o rutas directas desde /images según la configuración del proyecto.
- Mantener buen responsive: mobile-first real, con galería usable en celular.
- Optimizar imágenes con loading="lazy" en las que no sean hero.
- No sobrecargar la página con demasiadas animaciones simultáneas.
